# Dev-Nepal

A modern web application for connecting developers in Nepal and fostering tech community growth.

## 🚀 About

Dev-Nepal is a community-driven platform built with [Next.js](https://nextjs.org) to bring together developers, learners, and tech enthusiasts across Nepal. Share knowledge, collaborate on projects, and grow together.

## 📋 Prerequisites

- Node.js 16+ 
- npm, yarn, pnpm, or bun

## 🏃 Quick Start

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📝 Development

- Edit `app/page.js` to modify pages
- Changes auto-refresh as you save
- Uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) for optimized fonts
